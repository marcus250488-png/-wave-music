# Wave Music v0.6.0
Player Android (Flutter) com YouTube (API oficial + player oficial incorporado).
- Inicio estilo streaming: mixes, em alta, estacoes, artistas, playlists e lancamentos
- Busca com buscas recentes e explorar por genero
- Fila de reproducao, letras sincronizadas (LRCLIB), playlists, favoritas e historico
- Abrir no YouTube Music (para ouvir com a tela apagada, pelo app do YouTube Music)
Precisa de chave gratuita da YouTube Data API v3 (engrenagem no Inicio).
