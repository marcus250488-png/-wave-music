# Wave Music v0.5.0
Player Android (Flutter) que usa o YouTube como fonte (API oficial de busca + player oficial incorporado).
- Musicas em alta no Brasil, busca por cantor/banda/musica e explorar por genero
- Playlists, favoritas e historico
- Letras sincronizadas (LRCLIB), fila, aleatorio, repetir e timer para dormir
Precisa de uma chave gratuita da YouTube Data API v3 (colada na engrenagem do Inicio).
Uso pessoal. O video fica visivel e a musica nao toca com a tela apagada (regra do player do YouTube).
